# AI-Augmented Software Development Manifesto

We are uncovering better ways of developing software with AI by doing it and helping others do it.

Through this work we have come to value:

- **Human agency and taste** over agentic autopilot
- **Tight human feedback loops** over long unattended agent runs
- **Reliable, tested software** over AI-generated sprawl
- **Clear, evolving intent** over comprehensive specs or vibe-coding

That is, while there is value in the items on the right, we value the items on the left more.

## Principles

1. **Ship real software, not AI theater.** Demos, benchmarks, token counts, and agent traces are not progress unless users get something reliable.
2. **Humans are still the bottleneck.** Taste, domain judgment, trade-offs, and the ability to say "no" matter more as output gets cheaper.
3. **AI output is raw material.** Generated code is not done until a human understands it, tests it, and owns it.
4. **Use AI to widen the option set, not make the call.** The model can suggest paths; it cannot know which path is worth taking.
5. **Keep the loop short.** State intent, generate, inspect, correct, and ship in small increments.
6. **Write intent when ambiguity is expensive.** Delete it when it becomes documentation theater.
7. **Prefer evaluation over vibes.** If you cannot tell whether the system improved, your process is mostly superstition.
8. **Run agents unattended only when failure is cheap and verification is clear.** Complex product work needs close human supervision.
9. **Refuse generated complexity.** AI makes abstractions, context bloat, and framework cosplay cheap to create and expensive to own.
10. **Protect your judgment.** If AI makes you faster but duller, you are losing.
